Stations from the Radio tab play on speakers as Radio Browser stations, by their Radio Browser id and with their logo, so a station saved to a preset keeps playing when it changes its stream URL, and plays through any Revive ST server. Casting no longer reads the speaker's account first. Configuring a speaker has it fetch the server's sources before restarting, so new sources work after that one restart.
