# Speakers Domain Model

- **Speaker registry** (`registry/`): The app's speaker list, outside React: one record per device id holding who and where the speaker is and, once reached, its live state. It finds speakers (remembered ones and the network scan), keeps their connections, and remembers the list. Screens read it with `useSpeakers()` / `useSpeaker(id)` and send commands with `useSpeakerCommands()`.
- **BoseSpeaker**: A listed speaker as the screens show it (`registry/types.ts`): the registry's record with its live state flattened.
- **Known speaker**: A speaker the phone has reached before, remembered with its name, model and last address (`known-speakers.ts`). On launch it's listed right away as **connecting**, tried at its last address while the network scan runs, and shown **offline** if it doesn't answer in time and the scan doesn't find it; **online** once reached. Known speakers stay listed until the user forgets them. Commands only go to online speakers (`online`); home lists all of them (`listed`).
- **Local Network intro**: On iOS the first scan triggers the system's Local Network prompt, so the first launch shows a screen explaining it, and no speaker is scanned for or connected to until the user continues. iOS doesn't tell the app when access was refused; screens where no speaker answers say where to turn it on.
- **Our server**: The Revive ST server picked in Settings (`https://api.revivest.app` by default, or a self-hosted one). The app talks to it and sets speakers up for it; a speaker whose `margeURL` is another server shows as needing setup.
- **Internet radio setup** (code: `features/configure`): Points a speaker at our server over its TAP console (port 17000): the bmx registry, stats, marge and software update addresses, then `envswitch boseurls set`, which saves them; pairs it with the household account and restarts it. A speaker is **set up** (status "Ready") when its `margeURL` is our server and it has an account; setup only finishes once the speaker, back from the restart, has contacted our server (its **last contact**, recorded by the server per device id).
- **Household account**: The Marge account a household's speakers are paired with, minted by our server. Its id is the secret that grants access to the household's presets, so only server-minted ids are shared between speakers. The phone remembers one per server.
