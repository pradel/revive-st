# Supported Speakers

Revive ST is designed to work seamlessly with **any speaker that used the original Bose SoundTouch app**. If the original app controlled it, Revive ST will too.

## Compatible Models

Below is a breakdown of the core SoundTouch models and their compatibility:

| Model                   | Compatibility   | Known Limitations |
| :---------------------- | :-------------- | :---------------- |
| **SoundTouch 10**       | Fully Supported | None              |
| **SoundTouch 20**       | Fully Supported | None              |
| **SoundTouch 30**       | Fully Supported | None              |
| **SoundTouch Portable** | Fully Supported | None              |
