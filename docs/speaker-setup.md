## Android

The Bose SoundTouch 10 broadcasts an open WiFi access point with a minimal DHCP server that is too slow to satisfy Android's strict DHCP client timeout, causing the connection to fail at the IP assignment stage. The fix bypasses this failure point entirely by using Android's ConnectivityManager.requestNetwork() API with NET_CAPABILITY_INTERNET explicitly removed from the NetworkRequest. This causes the onAvailable() callback to fire at L2 association — before DHCP even begins — at which point bindProcessToNetwork() is called to route all app traffic through that network. Android never gets a chance to reject it for lacking internet, and the app can communicate directly with the speaker at its well-known static IP 192.0.2.1 without ever needing a DHCP-assigned address.
